# Sunrise Dental Clinic Management System

A web-based dental clinic management system developed using Java, JSP, Servlets, MySQL and Apache Tomcat.

## Main Features

- User login and session management
- Appointment registration and search
- Dentist management
- Appointment conflict detection
- Billing and receipt generation
- Dashboard statistics
- Clinic management reports
- HTTP/JSON appointment API
- MySQL stored procedure, trigger and function
- JUnit-based testing

## Technologies Used

- Java 21
- JSP and Servlets
- Apache Tomcat
- MySQL
- JDBC
- Maven
- JUnit 5
- Git and GitHub

## Version Control

The project is maintained using Git and GitHub with incremental commits, feature branches, merges and versioned releases.
